# GDP-ANALYSIS

## Overview
This project was completed as part of internship practice.  
The project analyzes GDP, population, climate, and economic data of different countries using Machine Learning techniques.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Flask
- Joblib

## Dataset
- Countries_and_continents_of_the_world.csv

## Features
- Data preprocessing
- Missing value handling
- Outlier removal
- Data visualization
- GDP analysis
- HDI category prediction
- Machine learning model training
- Model evaluation
- Model saving and loading

## Visualizations
- Bar Chart
- Heatmap
- Histogram
- Pie Chart
- Treemap

## Machine Learning Model
- Random Forest Classifier

## Accuracy
- 81.08%

## Output
The trained model predicts HDI categories:
- Low
- Medium
- High
